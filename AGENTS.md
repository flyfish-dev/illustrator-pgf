# Repository Rules

1. Never execute input PostScript or plugin code.
2. Unknown syntax must remain byte-preserved and diagnosed.
3. Do not add a semantic handler without fixture ID, version range, operand schema and tests.
4. Do not mark a feature `supported/high` without real Illustrator corpus plus structural and visual Oracle.
5. Worker parsing is the production browser path; no silent main-thread fallback.
6. All new caches and decoded resources require a limit and dispose path.
7. Do not commit customer documents, commercial fonts, restricted ICC profiles, Adobe SDK files or binaries.
8. Golden updates require human review.
